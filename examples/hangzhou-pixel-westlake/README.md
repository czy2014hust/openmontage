# 像素版杭州·西湖夜游

Douyin-style voxel night city remake of the viral Harbin pixel tour, built as a HyperFrames + Three.js atelier composition.

## Preview / render

```bash
cd examples/hangzhou-pixel-westlake
npx hyperframes check
npx hyperframes render --output out.mp4 --fps 30 --quality draft
```

Vertical 9:16 (1080×1920), 12s, seekable Three.js camera path over West Lake / Leifeng Pagoda / Broken Bridge / Hefang lights.

Production run artifacts live under `projects/hangzhou-pixel-westlake/` (gitignored).
